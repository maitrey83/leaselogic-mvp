#### Utah Code §57-22-4 (Notice Requirements)
**Citation:** Utah Code Ann. § 57-22-4
**Topic:** Notice requirements for rental agreements

**Relevant Provisions:**
- Minimum notice period requirements for tenancy changes
- 15 days written notice required for month-to-month tenancies
- 5 days written notice required for week-to-week tenancies

**Template Implementation:**

increase can take effect.

#### Utah Code §57-22-6 (Retaliatory Conduct)
**Citation:** Utah Code Ann. § 57-22-6
**Topic:** Prohibition on retaliatory actions by landlords

**Relevant Provisions:**
- Landlord may not retaliate against tenant for lawful actions
- Protected tenant activities (complaints, repairs, legal rights)
- Rebuttable presumption of retaliation within certain timeframes

**Template Implementation:**
```

including but not limited to filing complaints, requesting repairs, or
exercising your legal rights.

as prohibited by Utah Code §57-22-6.
```

**Review Questions:**
